# Security Policy

## Supported Versions

Security fixes are released for the latest release of Django Ninja.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately, either:

- through GitHub's [private vulnerability reporting](https://github.com/vitalik/django-ninja/security/advisories/new), or
- by email to **ppr.vitaly@gmail.com**

Please include a description of the issue, the affected version(s), and steps or a minimal example to reproduce it.
You should receive a response within a few days. Once the issue is confirmed, a fix will be prepared and released,
and you will be credited in the release notes unless you prefer otherwise.
